# Internship Onboarding Checklist

## Offer Letter

- Read the offer letter carefully.
- Confirm role, dates, stipend if any, reporting manager, and working hours.
- Sign only if you agree with the terms.
- Scan or photograph the signed document clearly.
- Send it back from your own email address.

## Suggested Reply Email

Subject: Signed Internship Offer Letter - Manish

Dear Team,

Thank you for sharing the internship offer letter. Please find attached the signed copy for formal onboarding.

I am excited to contribute to the Hospital and Ambulance Aggregator Website project.

Best regards,
Manish

## Project Preparation

- Install Node.js if it is not already installed.
- Learn the basics of HTML, CSS, JavaScript, REST APIs, and SQL.
- Keep notes of tasks completed each day.
- Ask for clarification when requirements are unclear.
